# Cellular Functional Architecture (CFA)

Status: Part 1A source and representation policy frozen with explicit approval; Part 1B molecular harmonization in progress. See `manifests/P1A_SOURCE_LOCK_V1.json` for historical candidate commit and exact fingerprints.

## Objective
Test whether independent molecular architecture, natural cellular variation and experimentally measured functional phenotypes converge on reusable biological capabilities.

Biological scope: human macrophages, fibroblasts and endothelial cells. A common human molecular knowledge graph is proposed; actual cell-specific deployment is a later independent analysis.

## Phase boundaries
- Part 1: molecular knowledge only; candidate architectures, not validated physiological functions.
- Part 2: independently derived expression programmes in the three lineages.
- Part 3: frozen cross-view convergence tests.
- Part 4: independent functional perturbation evidence.
- Part 5: functional specialization and cross-context transfer.
- Part 6: multicellular orchestration, spatial and temporal tests.

See `protocol/PART1_MATHEMATICAL_PROTOCOL.md` and `registries/` for the formal specification and audit trail. Raw data, large results and logs remain outside Git tracking. Source certification passed within audited roles; graph inference and biological validation remain pending.
