Reactome v98 release announcement lists database dumps separately as CC BY 4.0, whereas current data clause describes data and derived files as CC0. Retain conservative attribution and do not redistribute deferred dumps without checking artifact-specific terms. Apply attribution to all sources regardless of waiver; for CC BY include creator, source, version, license link and modification notice. Keep source-specific terms for combined outputs; do not assert blanket CC0 for integrated data. GO-derived imports retain GO attribution and Reactome source provenance. External cross-reference identifiers do not imply permission to redistribute third-party databases. Reference links: https://creativecommons.org/licenses/by/4.0/ and https://creativecommons.org/publicdomain/zero/1.0/. No software license selected here. Source receipts are immutable; overlay reviewed license metadata rather than edit historical receipts.
